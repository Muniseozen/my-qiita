# はじめに

Qiitaの記事はブラウザから直接書くこともできますが、**GitHubで管理すると次のメリットがあります。**

- GitHubで履歴管理できる
- バックアップになる
- チームレビューができる
- pushするだけでQiitaに自動投稿できる

今回は **GitHub Desktopを使って、ターミナルなしで管理〜自動投稿まで** を1記事で完結させます。

---

# 1. GitHubでリポジトリを作成

まず、Qiita記事を管理するための **GitHubリポジトリ** を作成します。

![my-Qiita.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/decc3b43-c1c3-4581-bb12-0d1ef84fbc54.png)

設定は次のようにします。

| 項目 | 日本語 | 設定 |
|---|---|---|
| Repository name | リポジトリー名 | my-qiita |
| Description | 説明 | Source repository for my Qiita articles |
| Visibility | 公開・非公開 | Public |
| Add README | README追加 | Off |
| Add .gitignore | .gitignoreの追加 | None |
| License | ライセンス | None |

設定が完了したら **Create repository** をクリックします。

---

# 2. GitHub Desktopでリポジトリをクローン

次に、作成したリポジトリを **GitHub Desktop** を使ってローカル環境にクローンします。

GitHub Desktopを開き、リポジトリ一覧から **my-qiita** を選択します。

![github-desktop-clone.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/8f753888-94a9-4eca-bd22-e9fa1d0ddae2.png)

保存先のフォルダを選択し、**Clone** をクリックします。

![スクリーンショット 2026-03-08 0.26.48.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/5b02cfc5-c6db-4b2c-a764-f0f3febba5fd.png)

これでローカル環境にリポジトリがダウンロードされます。

# 5. Qiita CLIをセットアップする

GitHubからQiitaへ自動投稿するために、**Qiita CLI** を使います。

### 5-1. Qiitaのアクセストークンを取得

1. Qiitaにログインし、右上のアイコン → **設定** を開く
2. **アプリケーション** → **個人用アクセストークン** → **新しいトークンを発行する**
3. スコープは `read_qiita` と `write_qiita` にチェック
4. 発行されたトークンをコピーしておく（再表示されないので注意）

![token-crate.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/bfcc8842-f86c-48fb-b130-e12e80820af9.png)

![token-copy.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/22b98bc5-a71f-442d-952c-b0068a8db97e.png)

### 5-2. GitHubにシークレットを登録

1. GitHubの **my-qiita** リポジトリを開く
2. **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
3. 以下を入力して **Add secret**

| 項目 | 値 |
|---|---|
| Name | `QIITA_TOKEN` |
| Secret | 先ほどコピーしたトークン |

![token-github.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/6016f792-5292-4e09-90e2-b35d2fac2e58.png)

# 6. GitHub Actionsで自動投稿を設定する

### 6-1. ワークフローファイルを作成

VS Codeで以下のフォルダ・ファイルを作成します。

```
my-qiita
├── .github
│   └── workflows
│       └── publish.yml
└── public
    └── first-post.md
```

### 6-2. publish.yml の中身
![publish-yml.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/6516c817-3a53-47d5-b540-e3b585fbfde1.png)
```yaml
name: Publish to Qiita

on:
  push:
    branches:
      - main
    paths:
      - "public/**"

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: "20"

      - name: Install Qiita CLI
        run: npm install -g @qiita/qiita-cli

      - name: Publish articles
        run: qiita publish --all
        env:
          QIITA_TOKEN: ${{ secrets.QIITA_TOKEN }}
```

このワークフローは **`public/` 配下のファイルが変更されてmainにpushされたとき** に自動で実行されます。

# 7. GitHub Desktopでpush → Qiitaに自動反映

`first-post.md` に記事を書いて保存します。

```markdown
---
title: Qiita記事をGitHubで管理してみた
tags: Qiita GitHub Markdown
private: false
---

# はじめに

Qiita記事をGitHubで管理する方法を試してみました。
```

GitHub Desktopに変更が表示されたら：

1. 左下の **Summary** にコミットメッセージを入力
2. **Commit to main** をクリック
3. 右上の **Push origin** をクリック

![commit.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4257135/f7b67f48-500a-47a6-8d22-aabe42142b61.png)

pushが完了すると GitHub Actions が自動で起動し、Qiitaに記事が投稿されます。

Qiitaの自分のページを開いて、記事が反映されていることを確認してください。
